`fiber_network_14871.geo.h5`: the small paper network of Hauck & Rupp (2024), "Fiber network
models of paper", https://doi.org/10.5281/zenodo.12751486 (CC BY 4.0), converted by HyperHDG's
old `domains/morgan/make_geo.py`, which split the fibers at the bond points, into the .geo file
the cython-era `reproducibles_python/fiber_network_*.py` ran on, then by HyperHDG's
`python/geo2h5.py` into this file: 10726 nodes, 14871 edges, 12 property columns. The example
gives the identical CG history on both formats. Kept here because the old converter is gone and
the file cannot be regenerated byte for byte; the golden files `tests/golden/reproducible_*.json`
refer to it.
